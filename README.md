# F3 RVA WordPress Theme

A clean and modern WordPress theme designed for the F3 RVA community. This base theme provides a solid foundation for fitness and community-focused websites.

## Features

- **Responsive Design**: Mobile-first approach with clean, modern styling
- **WordPress Standards**: Built following WordPress coding standards and best practices
- **Accessibility Ready**: Includes proper semantic markup and screen reader support
- **Custom Navigation**: Primary and footer navigation menus
- **Widget Areas**: Sidebar and footer widget areas for customization
- **Theme Customizer**: Built-in customization options through WordPress Customizer
- **SEO Friendly**: Clean markup and proper heading structure
- **Translation Ready**: All strings are translatable using the 'f3rva' text domain

## Installation

1. Download or clone this repository
2. Upload the theme folder to your WordPress `/wp-content/themes/` directory
3. Activate the theme through the WordPress admin panel
4. Customize the theme through Appearance > Customize

## Theme Structure

### Core Files
- `style.css` - Main stylesheet with theme information
- `index.php` - Main template file
- `functions.php` - Theme functions and features
- `header.php` - Header template
- `footer.php` - Footer template
- `sidebar.php` - Sidebar template

### Template Files
- `single.php` - Single post template
- `page.php` - Page template
- `search.php` - Search results template
- `404.php` - 404 error template
- `comments.php` - Comments template
- `searchform.php` - Search form template

### Assets
- `assets/js/main.js` - Theme JavaScript for navigation and interactions

## Customization

### Menus
Navigate to **Appearance > Menus** to set up:
- Primary Navigation (main site navigation)
- Footer Navigation (footer links)

### Widgets
Navigate to **Appearance > Widgets** to customize:
- Primary Sidebar
- Footer Widgets

### Theme Options
Navigate to **Appearance > Customize** to modify:
- Site Identity (logo, title, tagline)
- Footer Text
- Colors and Background

## Development

This theme is built as a base template and can be extended with:
- Child themes for safe customization
- Additional template files for custom post types
- Custom CSS through the theme customizer
