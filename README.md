# F3RVA WordPress Theme

A minimalist WordPress theme focused on post listings and post details. Clean, lightweight design optimized for readability and performance.

## Features

- **Minimalist Design**: Clean, distraction-free layout focused on content
- **Post-Centric**: Optimized for blog posts with excellent archive and single post layouts
- **Responsive**: Mobile-first design that works on all devices
- **Performance**: Lightweight with minimal JavaScript and optimized CSS
- **Accessibility**: WCAG-compliant with proper semantic markup
- **Modern WordPress**: Full support for WordPress 6.0+ features including block editor
- **SEO Ready**: Proper semantic HTML and meta tags

## Theme Structure

### Core Templates
- `index.php` - Main template for post listings
- `single.php` - Individual post template
- `archive.php` - Category and tag archive template
- `page.php` - Static page template
- `404.php` - Error page template
- `header.php` - Site header
- `footer.php` - Site footer
- `comments.php` - Comments template

### Styling
- `style.css` - Main theme stylesheet with responsive design
- `editor-style.css` - WordPress editor styles
- `theme.json` - Block editor configuration

### JavaScript
- `js/theme.js` - Minimal theme scripts for mobile menu and accessibility

## Installation

1. Download or clone this repository
2. Upload to your WordPress `wp-content/themes/` directory
3. Activate the theme in WordPress Admin → Appearance → Themes

## Customization

The theme supports WordPress customizer and includes:
- Custom logo support
- Primary navigation menu
- Post thumbnail support
- Block editor styles
- Responsive embeds

## Browser Support
